# Oráculo Diosa Fortuna Professional 1.0.0

Primera versión estable y publicable.

## Incluye

- Motor Fortuna y Score Breakdown.
- Modelo PIT configurable y versionado.
- Laboratorio, backtesting y Centro PIT.
- Comparador de versiones.
- ATHENA Analista PIT.
- Métricas PIT y Auditor PIT.
- Simulador PIT.
- Dashboard Premium.
- Reportes PDF.
- Centro de Ayuda y diagnóstico.
- Distribución automatizada para Android, Web y Windows.

## Distribución

El workflow **Publish Professional Release** genera un AAB firmado, APK, ZIP web y ZIP Windows, y los agrega a una GitHub Release.

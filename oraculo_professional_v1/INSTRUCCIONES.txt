ORÁCULO DIOSA FORTUNA PROFESSIONAL v1.0

Esta es una reconstrucción limpia del proyecto.

PASOS PARA REEMPLAZAR EL PROYECTO DEL REPOSITORIO:

1. Haz una copia de seguridad de la carpeta actual del repositorio.
2. Conserva la carpeta oculta .git del repositorio clonado.
3. Borra el resto del contenido del repositorio local.
4. Copia dentro TODO el contenido de esta entrega, incluida .github.
5. Abre GitHub Desktop.
6. Escribe: Reconstrucción limpia Professional v1.0
7. Pulsa Commit to main.
8. Pulsa Push origin.
9. En GitHub > Actions ejecuta Build Windows Installer.

El workflow primero ejecuta:
- flutter analyze
- flutter test
- flutter build windows --release

Si Analyze o Test fallan, no construirá una versión defectuosa.

# Oráculo Diosa Fortuna — Flutter Fase 4

Esta fase prepara un instalador real de Windows mediante GitHub Actions e Inno Setup.

## Entregables automatizados

- `Oraculo_Diosa_Fortuna_Setup.exe`
- versión portátil de Windows;
- APK de Android;
- AAB para Google Play;
- compilación web.

## Archivos principales

- `.github/workflows/build_windows.yml`
- `.github/workflows/build_android.yml`
- `installer/oraculo_installer.iss`
- `INSTRUCCIONES_FASE4.txt`
- `store_assets/politica_privacidad.html`
- `store_assets/ficha_google_play.txt`

La aplicación sigue siendo una herramienta estadística. No garantiza premios.
